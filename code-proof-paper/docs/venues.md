Venue Selection Guide and Submission Strategy

## Selection Criteria
- Scope fit: math vs. CS theory vs. PL/formal methods vs. domain venue.
- Code and artifact friendliness: artifact evaluation tracks, open science policies.
- Review model: single-blind, double-blind, rolling review.
- Format constraints: page limits, template requirements, anonymization.
- Timelines: submission windows and typical decision times.

## Candidate Venues (illustrative, verify current calls)
- Journals: Journal of Automated Reasoning, Logical Methods in Computer Science, ACM Transactions on Computational Logic, Journal of Formalized Reasoning.
- Conferences/workshops: CPP, ITP, POPL (artifacts), OOPSLA (artifacts), FMCAD, CAV, FSCD. Domain venues where code-backed proofs are welcome.

## Steps
1. Shortlist 3 venues; compare scope, length, and artifact policies.
2. Adopt the venue’s LaTeX template early (or keep generic and switch later).
3. If artifacts are evaluated, prepare a clean, documented package with one-command setup.
4. Ensure anonymization: scrub author names, metadata, and repo links if required.
5. Create a calendar for submission, rebuttal, and camera-ready deadlines.
