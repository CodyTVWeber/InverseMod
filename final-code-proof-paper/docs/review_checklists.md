Author and Reviewer Checklists

## Author Pre-Submission
- [ ] Every symbol defined on first use; consistent notation.
- [ ] Theorem statements precise; hypotheses explicit.
- [ ] `docs/ARTIFACTS.md` maps each claim to code/tests and commands.
- [ ] One-command paper build and one-command test run.
- [ ] Environment recorded (`docs/environment.txt`).
- [ ] Figures and algorithms referenced and legible.
- [ ] Reproducibility on a clean machine verified.

## Internal Reviewer
- [ ] Claims trace to code/tests; no gaps.
- [ ] Counterexamples explored; edge cases covered.
- [ ] Proof sketch aligns with executable checks.
- [ ] Writing clarity: motivation, scope, limitations.
- [ ] Build scripts robust and documented.

## Artifact Evaluation (if applicable)
- [ ] Clean setup using provided script; pinned dependencies.
- [ ] Tests pass; properties demonstrate the stated results.
- [ ] Deterministic seeds or justified nondeterminism.
- [ ] Minimal trusted kernel identified and isolated.
